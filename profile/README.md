<p>第二项，归属一致。注册机构、地区、用途标注，三项要在不同时间查询都指向同一个结论。查询结果摇摆，说明段被重新分配过。</p>

<p>四项做完，结论通常很明确：这是真静态还是长租，质量是在维持还是在下降。两种都能用，但预期要调整。</p>

<p>评测时建议控制变量。换时段测的时候，请求内容、并发、间隔都保持一致，否则数据不可比。</p>
